# Chọn phong cách hình ảnh

Đọc `studio-bible/PHONG-CACH-HINH-ANH.md`, chọn một preset theo chức năng sư phạm và đọc file tương thích tương ứng.

| Nhu cầu | ID sản xuất |
|---|---|
| Người thật, lớp học, thí nghiệm thật | `LIVE-TEACHER` |
| Vi mô, cấu tạo bên trong, thiên văn | `SCIENCE-3D` |
| Người thật cần overlay giải thích | `LIVE-3D-HYBRID` |
| Sơ đồ nguyên lí 2D phẳng | `EDU-FLAT-2D` |
| Giải bài hoặc chứng minh từng bước | `STEP-WHITEBOARD` |
| Kể chuyện có nhân vật và chuyển thang | `COSMIC-STORY-2D` |
| Công thức, quan hệ biến và kinetic type | `MATH-MOTION` |

Nếu người dùng viện dẫn một thương hiệu/kênh, chỉ rút ra thuộc tính cấp cao họ muốn; không đưa tên thương hiệu, logo, mascot hoặc câu “in the style of” vào prompt sản xuất. Không trộn preset trừ `LIVE-3D-HYBRID` hoặc khi continuity bible mô tả rõ điểm chuyển.
