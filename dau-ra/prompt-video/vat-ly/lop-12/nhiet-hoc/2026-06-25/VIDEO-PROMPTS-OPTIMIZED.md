## 📋 HƯỚNG DẪN SỬ DỤNG

1. **Chuẩn bị 6 ảnh reference:**
   - SCENE-1-A.png, SCENE-1-B.png, ... SCENE-1-F.png (từ IMAGE PROMPTS)

2. **Paste VIDEO PROMPTS:**
   - Copy VIDEO 1 block → paste vào **Kling / MiniMax** prompt box
   - Upload reference image: SCENE-1-A.png
   - Generate → Save as `SCENE-1-A.mp4` (≤9s)
   - Lặp lại VIDEO 2–6

3. **Ghép clips (FFmpeg):**
   ```bash
   ffmpeg -i "concat:SCENE-1-A.mp4|SCENE-1-B.mp4|SCENE-1-C.mp4|SCENE-1-D.mp4|SCENE-1-E.mp4|SCENE-1-F.mp4" -c copy output-video.mp4
   ```

4. **Add voice (từ voice script):**
   ```bash
   ffmpeg -i output-video.mp4 -i voice-60s.wav -c:v copy -c:a aac final-video.mp4
   ```

**Kết quả:** Video 60 giây hoàn chỉnh (1280×720, H.264, MP4)
