# ⚙️ PHẦN 4: GHÉP VIDEO (FFmpeg)

Lệnh để ghép 6 clips + add voice:

```bash
# Step 1: Concat video clips
ffmpeg -i "concat:SCENE-1-A.mp4|SCENE-1-B.mp4|SCENE-1-C.mp4|SCENE-1-D.mp4|SCENE-1-E.mp4|SCENE-1-F-A.mp4|SCENE-1-F-B.mp4" -c copy temp-video.mp4

# Step 2: Add audio (voice)
ffmpeg -i temp-video.mp4 -i voice-60s.wav -c:v copy -c:a aac -strict -2 final-video.mp4

# Step 3: Verify (optional)
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1:noprint_names=1 final-video.mp4
```

**→ Output: `final-video.mp4`**
- Duration: 60 giây
- Resolution: 1280×720
- Format: H.264 + AAC
- File size: ~30–50 MB
