# Kho tài liệu Hóa học

Thư mục lưu trữ tri thức nền tảng và tài liệu người dùng môn Hóa học:
- `KNOWLEDGE-BASE-CHUAN.md`: Kiến thức chuẩn hóa cốt lõi.
- `nguon-chinh-thuc.md`: Văn bản quy phạm và chương trình.
- `lop-6/` đến `lop-12/`: Tri thức theo từng khối lớp.
- `phet/`: Danh mục mô phỏng PhET môn Hóa học.
- Để nạp tài liệu riêng của bạn (SGK, giáo án, đề thi), hãy copy vào `tai-lieu-nguoi-dung/` trong từng thư mục lớp.
