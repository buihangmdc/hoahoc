# Command: /tao-hoat-dong-phet

`/tao-hoat-dong-phet [lớp] [bài/chủ đề] [thời lượng]`

Gọi `chuyen-gia-mo-phong-phet`, skill `day-hoc-voi-phet` và skill `thiet-ke-bai-day-hoa-hoc`. Xuất: ánh xạ SGK/source ID, mục tiêu, link PhET Hóa học, phiếu POE+C, biến (nồng độ, áp suất, nhiệt độ, pH), bảng dữ liệu, câu hỏi, đáp án gợi ý, lỗi sai thường gặp, giới hạn mô hình và phương án lớp học ít thiết bị.
